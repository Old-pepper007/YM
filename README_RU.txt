Сборка YM_matcher.app для MacBook Air M1 без установки Python на самом Mac

Важно: этот комплект нужно один раз собрать на облачном macOS-компьютере GitHub Actions.
После сборки на Mac будет скачан готовый YM_matcher.app; Python устанавливать на Mac не нужно.
Для облачной сборки понадобится учётная запись GitHub.

1. Распакуйте архив на компьютере.
2. Войдите на github.com и создайте новый пустой репозиторий (например, YM-matcher-mac).
3. Загрузите в репозиторий все файлы и папки из этого архива, включая скрытую папку .github.
   В репозитории должен появиться файл .github/workflows/build-macos.yml.
4. Откройте вкладку Actions в репозитории. Если GitHub попросит разрешить workflows, подтвердите.
5. Слева выберите “Build macOS app”, затем “Run workflow” → “Run workflow”.
6. Дождитесь зелёной отметки успешного выполнения. Откройте завершённый запуск и скачайте artifact YM_matcher_macOS_M1.
7. Распакуйте скачанный ZIP. Внутри будет YM_matcher.app.
8. Скопируйте YM_matcher.app в папку отчёта рядом с двумя Excel-файлами:
   - zvonko_in.xlsx
   - ZVONKO Digital X Яндекс Музыка.xlsx
9. Запустите YM_matcher.app двойным щелчком. После завершения появится окно подтверждения.

Выходные файлы:
- zvonko_out_YM.xlsx
- Нет в zvonko - YM.xlsx

Если возникнет ошибка, рядом с приложением появится YM_matcher_error.txt.

Примечание: приложение не подписано сертификатом Apple Developer ID, поэтому macOS может показать предупреждение при первом запуске. В таком случае откройте Системные настройки → Конфиденциальность и безопасность и разрешите запуск приложения, только если вы уверены, что скачали его из своего репозитория.
